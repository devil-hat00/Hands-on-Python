# Portfolio – Flask Web Application
A modern, dark-themed personal portfolio built using Flask, showcasing my work as an engineer, innovator, and CEO of Torque Zero. This site includes my major projects, skills, achievements, and a clean contact section—all wrapped in a responsive, futuristic UI.

🚀 Features
Sleek dark UI with neon green accents
Single-page smooth scrolling
Fully responsive layout
Sections for About, Projects, Skills, Achievements & Contact
Hover animations and minimalistic design
Lightweight Flask backend


▶️ How to Run
pip install -r requirements.txt
python app.py

Open your browser at:
http://127.0.0.1:5000/
