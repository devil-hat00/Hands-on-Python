# 🎬 Movie Entry Checker – Python
A simple and beginner-friendly Python program that checks whether a person is allowed to watch a movie based on their age and ticket availability.
Great for practicing conditional statements, boolean handling, and basic input processing.

# 🚀 Features
Takes user input for age
Accepts ticket availability as boolean (1/0)
Applies movie entry rules:
  Age > 18 → Allowed + ID required
  Age < 15 → Allowed only with parents
  Else → Not allowed
Clear printed output for every condition

# 📌 How It Works
User enters age
User enters ticket status (1 = Yes, 0 = No)
Program checks eligibility
Displays appropriate message:
  "You can go inside"
  "You need parents"
  "You are not allowed"
