# Positive & Negative Number Checker in Python
A simple and beginner-friendly Python program that checks whether a given number is positive, negative, or zero. This mini-project is perfect for those learning basic Python concepts like user input, conditional statements, and decision-making.

🚀 Features
Accepts any numeric input
Checks if the number is positive, negative, or zero
Simple and readable code
Perfect for Python beginners

🧠 How It Works

The program:
Takes input from the user
Converts it into a number
Uses if, elif, and else conditions to classify the number


📌 Requirements

Python 3.x
▶️ How to Run
Install Python from https://python.org
Save the script as checker.py
Run it using:
python checker.py

📚 Learning Outcome
Understanding data type conversion
Using conditional statements
Basic input/output handling
