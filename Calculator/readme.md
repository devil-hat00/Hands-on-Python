# Python Calculator
A beginner-friendly terminal-based calculator built in Python. This project performs basic arithmetic operations and demonstrates the use of loops, conditionals, user input, and error handling in Python.

Features
Addition
Subtraction
Multiplication
Division
Modulus
Input validation (handles non-numeric inputs)
Clean, easy-to-understand menu
Safe exit option
How It Works
The calculator runs inside a continuous loop and allows the user to choose an operation. After selecting an option, the user enters two numbers, and the result is displayed instantly.

Invalid inputs or incorrect menu choices are handled gracefully using try-except blocks and conditional statements.

Requirements
Python 3.x
Works in Jupyter Notebook, VS Code, PyCharm, or terminal
No additional modules needed.
