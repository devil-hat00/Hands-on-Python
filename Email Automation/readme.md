# 📧 Python Email Automation using Gmail SMTP
This project demonstrates how to send emails directly from a Python script using Gmail’s SMTP server. It uses Python’s built-in smtplib, ssl, and email.message libraries — making it lightweight, simple, and reliable.

🚀 Features
Send automated emails using Python
Uses Gmail’s secure SMTP server
Fully customizable sender, receiver, subject, and message
Works with Gmail App Passwords
Clean, easy-to-understand code
Beginner-friendly project

🛠️ Tech Stack
Python 3
smtplib
ssl
email.message (EmailMessage)

📂 Project Setup
1️⃣ Install Python (if not already installed)
https://www.python.org/downloads/

2️⃣ Enable App Password in Gmail
Because Google no longer supports “less secure apps”, you must create an App Password:
Go to Google Account → Security
Enable 2-Step Verification
Go to App Passwords
Generate a new 16-character password
Paste it into your code


▶️ How to Run
python email_sender.py

📝 Output
The receiver will instantly get an email with your custom subject and message.
