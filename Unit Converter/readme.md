# Python Unit Converter

A simple, menu-driven **Python Unit Converter** that allows you to convert units across four major categories:

- **Length**
- **Mass**
- **Temperature**
- **Currency**

Each category includes **five of the most commonly used conversions** in daily life.

---

## 🚀 Features

✔ 4 main categories  
✔ 5 sub-conversions in each category  
✔ Beginner-friendly Python code  
✔ Easy to extend and customize  
✔ Clean menu-driven CLI interface  

---

## 📂 Categories & Conversions

### **1. Length**
- Meter → Kilometer  
- Kilometer → Meter  
- Meter → Centimeter  
- Foot → Meter  
- Inch → Centimeter  

### **2. Mass**
- Kilogram → Gram  
- Gram → Kilogram  
- Kilogram → Pound  
- Pound → Kilogram  
- Ounce → Gram  

### **3. Temperature**
- Celsius → Fahrenheit  
- Fahrenheit → Celsius  
- Celsius → Kelvin  
- Kelvin → Celsius  
- Fahrenheit → Kelvin  

### **4. Currency** (Static conversion rates)
- INR → USD  
- USD → INR  
- INR → EUR  
- EUR → INR  
- USD → EUR  

> *Note: Currency rates are static and can be modified easily.*

---

## 🧠 How It Works

The program shows a category menu.  
You select one category → choose a conversion type → enter the value → get the converted result.

---

## ▶️ Run the Program

1. Install Python (if not installed)
2. Download or clone this repository:
   ```bash
   git clone https://github.com/your-username/Unit-Converter.git
   ```
3. Run the script:
   ```bash
   python converter.py
   ```
